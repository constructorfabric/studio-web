# Архитектурные схемы бэкенда

`studio-web-architecture.drawio` — исходник в формате draw.io (diagrams.net),
три страницы. Правится в desktop-приложении draw.io или расширением
**Draw.io Integration** для VS Code; файл — XML, поэтому диффы в PR читаемы.

| Страница | О чём |
|---|---|
| **1 · Контекст** | Кто говорит с бэкендом снаружи: фронт, Theia-сессии, Keycloak, LLM-провайдер, внешние сервисы, реестры, хранилища. Внутренность бэкенда — крупными слоями. |
| **2 · Сборка бинаря** | Что именно прилинковано: системные и платформенные гиры gears-rust, наши in-crate гиры, плагины с их vendor/priority. Плюс feature-флаги, разница дев/релиз, блок `[patch]` и связка двух реестров GTS. |
| **3 · Данные, профили, ловушки** | Хранилища и что в каком лежит, пять конфиг-профилей, конвейер доставки, фазы жизненного цикла гира и список граблей. |

## Что здесь считается источником истины

Схема — навигация, а не спецификация. Проверяемые вещи живут в коде:

- состав ассамбли — `src/registered_gears.rs` и `mod`-ы в `src/main.rs`;
- feature-флаги и источники зависимостей — `Cargo.toml` (включая блок `[patch]`);
- флаги сборки, дев и релизной — `.github/workflows/studio-delivery.yml`;
- приоритеты плагинов — секции `*-plugin.config.priority` в `config/*.yaml`
  (у `studio-authz-plugin` секции нет — работает дефолт `priority: 40`);
- типы GTS — `cargo run -- gts-types` → `docs/gts-types.json`, тесты
  `src/gts_inventory.rs`, аудит живого стенда `cargo run -- gts-audit`.

Расхождение схемы с кодом — баг схемы. Если правишь состав гиров, профиль или
феатуру, поправь и соответствующую страницу в том же PR.

Числа на схеме — снимок, а не инвариант. Пересчитать их можно так:

```bash
find src -name '*.rs' | xargs cat | wc -l          # объём своего кода
wc -l config/*.yaml                                 # размеры профилей
grep -c 'use .* as _;' src/registered_gears.rs      # платформенных гиров
```

## Что рядом, но не здесь

У каждого компонента в `src/<компонент>/README.md` есть свой файл: зачем он
существует, чем владеет, какие ручки отдаёт. Схема отвечает на вопрос «как это
собрано вместе», README компонента — «что это за штука».

## Смежные документы

- `../../../docs/adr/` — решения уровня продукта (фронт, навигация, роли).

- `../graph-storage-*.md` — граф: API, быстрый старт, отчёт со стенда.
